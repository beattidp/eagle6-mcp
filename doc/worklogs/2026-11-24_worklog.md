### Bugs Identified & Resolved
1. **EAGLE 6 `-C` commands hang under bare `xvfb-run`:**
   - *Cause:* EAGLE 6.6.0 (Qt4) defers dispatching `-C` commands until the editor window receives an X11 `FocusIn`/`WindowActivate` event. Bare `xvfb-run` has no window manager, so newly mapped windows never receive focus.
   - *Fix:* Added `src/eagle6_mcp/runner/_xvfb_focus_exec.py` to call `libX11.so.6` (`XRaiseWindow` + `XSetInputFocus`) on mapped EAGLE editor windows inside Xvfb. Verified ~1–2s execution for both schematic and board exports.
2. **Legacy v5 binary-to-XML conversion (`WRITE; QUIT`) hung on confirmation prompt:**
   - *Cause:* Saving a pre-v6 binary file in EAGLE 6 XML format triggers a confirmation dialog.
   - *Fix:* Prepended `SET CONFIRM YES;` to `EagleRunner` CLI commands. Verified live conversion and XML parsing of `/home/beattidp/eagle/projects/counter-display/counter-display.sch` in ~2s.

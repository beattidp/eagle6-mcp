### Bugs Identified & Resolved
1. **EAGLE 6 `-C` commands hang under bare `xvfb-run`:**
   - *Cause:* EAGLE 6.6.0 (Qt4) defers dispatching `-C` commands until the editor window receives an X11 `FocusIn`/`WindowActivate` event. Bare `xvfb-run` has no window manager, so newly mapped windows never receive focus.
   - *Fix:* Added `src/eagle6_mcp/runner/_xvfb_focus_exec.py` to call `libX11.so.6` (`XRaiseWindow` + `XSetInputFocus`) on mapped EAGLE editor windows inside Xvfb. Verified ~1–2s execution for both schematic and board exports.
2. **Legacy v5 binary-to-XML conversion (`WRITE; QUIT`) hung on confirmation prompt:**
   - *Cause:* Saving a pre-v6 binary file in EAGLE 6 XML format triggers a confirmation dialog.
   - *Fix:* Prepended `SET CONFIRM YES;` to `EagleRunner` CLI commands. Verified live conversion and XML parsing of `/home/beattidp/eagle/projects/counter-display/counter-display.sch` in ~2s.

### Bugs Identified & Resolved (with Regression Tests)
1. **Uppercase Windows extensions (`.SCH`, `.BRD`, `.LBR`) hung EAGLE 6 on Linux:**
   - *Cause:* EAGLE 6.6.0 on Linux checks file extensions case-sensitively when selecting the schematic/board/library editor.
   - *Fix:* Added `EagleRunner._staged_filename()` to normalize staged file extensions to lowercase.
2. **False-positive value mismatches in `ConsistencyAnalyzer` on devicesets with `*`/`?` wildcards or `uservalue="yes"`:**
   - *Cause:* `SchematicAnalyzer.effective_value()` previously returned raw `part.deviceset` when `part.value` was omitted.
   - *Fix:* Implemented EAGLE 6's exact default value expansion (`uservalue="yes"` → `""`; otherwise substitute `*` with `technology` and `?`/suffix with `device`).
3. **False-positive package mismatches for embedded library version suffixes (`@1`, `@2`):**
   - *Cause:* EAGLE appends `@N` to duplicate embedded package names in schematics (e.g., `2X5M@1` vs `2X5M`).
   - *Fix:* Normalized `@\d+$` suffixes in `ConsistencyAnalyzer.check()`.
- Added regression test `test_effective_value_wildcard_and_package_suffix_regressions` (`pytest -v`: **16/16 passing** in 3.49s).

# EAGLE v6 MCP Plugin Bundle (`eagle6-mcp`)

Bundles the `eagle6-mcp` stdio MCP server (26 tools for CadSoft EAGLE v6.6.0 on Linux), the `eagle6-design-review` workflow skill, and forward/back-annotation safety rules into a single toggleable Antigravity plugin.

Source repository: https://github.com/beattidp/eagle6-mcp
